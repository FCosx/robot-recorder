# Pi 验收与待验证项目 — 2026-11-24

[English](pi-validation.md) | **简体中文**

主记录器为新更换的 Raspberry Pi 5 Model B Rev 1.1 / 8 GB，Ubuntu 24.04.5 / ROS 2 Jazzy，原生 ARM64 录制器、ext4 SSD 与千兆以太网。套装保留原 Pi 地址和录制。接收 DDS 域固定为 1；机器人源域是独立、可持久保存的 UI 设置。支持范围为标准 ROS 消息。

## 已完成验收

| 检查 | 证据 |
| --- | --- |
| 原生交付 | `20261124.pi1-9f079e13df30`；实际服务用户下的 15 编译模块及 ROS/依赖检查通过 |

| 录制优先 | 一次 LAN 检查的临时订阅 STOP 确认约 0.0156 秒；录制期间无测量、压缩或上传 |
| 启动 | 实际重启后 SSD、原生录制器、接收桥与 LoRa 代理恢复，测试源桥、云和无线控制端重新连接 |
| 数据保留 | 迁入的 7 包/48 文件逐一核对 SHA256 和整数纳秒修改时间；原 SSD 录制保留 |
| 页面状态 | 录制详情及迁移前 Uploaded 标识显示正常，云端连接可用、手动模式保持 |

这些是小负载功能验收。序号比较仅覆盖已录首尾消息之间，不能证明首尾之外的源数据完整。历史吞吐结果单独保留；本发布不将其称为新板的持续速率或温度实测。

共用桥保留监听器生命周期去重修复及 v2 实时 Image/CompressedImage 历史处理。源端安装配置有界 DDS 接收缓冲并保留自定义设置。接收端还保留带宽协调器恢复、源离线时的正常退出和简短 UDP/网络丢失风险提示。开始录制仍要求机器人确认临时测量订阅已关闭。没有警告不代表源消息绝对完整，也不提供任意传感器的精确缺失数。

已部署云端支持压缩校验上传、账号、单话题/四话题完整时间轴播放与拖动、Fast/HD、深度着色及 XYZ 交互点云；原始文件与下载不变。空间显示、管理员回收站/恢复/永久删除可用，自动删除关闭。首次预览准备或缓冲仍可能需要等待，尤其是大点云或慢网络。

## 公开发布检查

本次共发现 125 项 Python 测试，115 项通过、10 项因需要未公开的后端而跳过；4 个 JavaScript 测试文件全部通过。实际公开 LoRa 安装包的首次安装和更新检查通过，隔离配对/计数保持，内嵌手册与运行文件同仓库一致。两个桥归档、manifest 和架构头均与校验和一致；x86_64 桥还通过了实际临时安装/版本检查。Pi ELF 与先前已验收的 ARM64 构建相同。公开源码/资产排除检查、38 个本地链接/锚点及 38 段 shell 示例通过；这些发布检查没有修改电台、云端对象或生产记录器。

## 待验证项目，按优先级

1. **新 Pi 持续录制**：在历史已演示工作范围附近做集中延长测试，核对源消息数/载荷、SSD/USB 错误、CPU 温度及风扇表现。更换主板/散热后仍需验证。
2. **此 Pi 的小包云端到端检查**：压缩上传、停止/恢复、完整下载校验，以及传输排队时开始录制的优先级。功能在先前设备已测；迁移本身只核对了连接和历史上传状态，没有新上传。
3. **新机器人与实际场景**：在可用 Humble/Jazzy 机器人按发布命令完成安装，验证域切换/重启恢复和代表性传感器，并实际检查 NoMachine 操作及下载位置。
4. **远距离 LoRa**：在实际场地测命令/状态可靠性和话题/列表等待时间。轮询间隔为一秒，不保证一英里范围或每秒端到端更新。
