# Pi 验收与待验证项目 — 2026-11-26

[English](pi-validation.md) | **简体中文**

主记录器为 Raspberry Pi 5 Model B Rev 1.1／8 GB，Ubuntu 24.04.5／ROS 2 Jazzy，主动散热、原生 ARM64 录制器、通过 USB 3／UAS 连接的 Kingston A400 480 GB ext4 SSD，以及千兆以太网。Lenovo 作为机器人／发布源；操作笔记本仅打开网页和执行维护。Pi 接收域固定为 **1**，机器人源域可独立选择并保存。支持标准 ROS 消息。

以上是特定配置的有界测量，不是绝对速率上限或任意长时间无丢失保证。含预热／尾部的总消息数分别为 41,361／41,361 和 49,281／49,281。110 MiB/s 虽独立核对无缺失，接近网口容量的风险提示仍正确保留。此前以操作笔记本为源的一轮丢了 84／39,600 条；源电脑、配置、链路和域也发生变化，不能据此将改善单独归因于散热或某个硬件。

RealSense 的 header 时间在该驱动配置下精确对应，不等于独立硬件时钟精度或任意传感器完整性证明；场景中的无效深度仍保持无效。真实传感器录制保留，自有合成测试包在保存参考证据后删除。

重启测试开机初期曾有时钟偏差日志，原有 NTP 完成同步后停止；40 条消息验证在同步后进行。没有修改时钟策略，尚未验证未同步期间的时间敏感录制。

桥保留监听器生命周期去重修复和 v2 图像历史处理。即使当前缓冲已够大，安装器也会持久保存 DDS 接收上限，并保留更高的受管设置。开始录制前，临时带宽订阅必须关闭并确认。警告覆盖已报告丢失和已知压力／中断风险；没有警告**不等于任意发布器的数据绝对完整**。

云端支持带索引 Zstandard 压缩及校验上传、个人账号、下载、单话题／四话题完整时间轴与拖动、Fast／HD、深度着色及交互 3D 点云。预览是抽样副本。容量指示、管理员回收站／恢复／永久删除可用，自动删除保持关闭。首次预览准备或慢网络仍可能需要等待，不承诺独立 bag 备份。

## 发布检查

公开 Python 检查 120 项通过，10 项因需要私有后端跳过；4 个 JavaScript 测试全部通过。 实际公开 LoRa 首次安装及更新、加密配对身份、原有计数保持、内嵌手册／运行文件一致性、两个桥包哈希／架构及 x86_64 临时安装均检查。Pi ELF 与私有归档中的已部署构建一致。公开文件及展开后的归档检查凭据、运行状态和被排除的后端源码；发布检查不运行发布器，也不修改原录制或云对象。

## 待验证项目

1. **机器人与现场流程**：新 Humble／ARM64 安装及代表性传感器；可达 Wi-Fi 与 NoMachine 操作和下载位置。已在 Lenovo／Jazzy x86_64 按公开首次命令安装，但不能替代 Orin／Humble 现场验收。
2. **实际远距离 LoRa**：目标场地的命令／状态可靠性、重连及话题／目录等待时间。当前空中速率下大目录可能较慢；一秒轮询是收到回复后的等待，不保证一秒端到端更新或一英里距离。
3. **长时及故障边界证据**：任意传感器的完整性、时钟同步前启动、突然断电／拔线，以及低空间自动停止后 bag 的独立复读仍待补；没有进行破坏性满盘或断电试验。
