# 机器人数据记录器

[English](README.md) | **简体中文**

用于机器人实验的 ROS 2 数据记录器。机器人通过以太网和 Zenoh 将话题传到树莓派；用户在局域网浏览器中选择话题并控制录制，MCAP 文件保存在树莓派。

**树莓派是项目的主录制平台。** 请从当前 `main` 分支及下方 Pi 使用手册开始。[Lenovo 分支](https://github.com/FCosx/robot-recorder/tree/lenovo-recorder)保留 Lenovo/NVMe 备选方案及其历史 beta；其中的 x86_64 录制器可执行文件不能用于 Pi。已发布安装器与维护中的实机软件分别管理版本。

## 主要功能

- 发现并选择 ROS 2 话题，开始/停止录制，按大小或时长切分 MCAP。
- 两端 UI 可修改机器人桥监听的 ROS 域，保存在机器人上，重启后继续使用。
- 刷新时估算话题带宽；开始录制前关闭临时测量订阅。
- 查看录制大小、时长、各话题消息数及平均 Hz，下载或删除录制。
- 显示空间、温度、机器人连接状态和简短录制警告。
- 可选 HTTPS/S3 云上传：先做带索引的 Zstandard 无损压缩，支持手动/空闲自动上传、停止/恢复及上传校验；录制始终优先。
- 云端登录与下载、单话题/最多四话题同步回放、Fast/HD 图像、深度着色及交互式 3D 点云。
- 可通过 NoMachine 使用机器人上的浏览器，无需操作笔记本始终接交换机网线。

## 最新修复

- 即使临时缓冲已够大，也持久保存 DDS 接收缓冲设置；Lenovo 机器人重启后无需登录即可重新连接。
- 每个带宽助手使用独立 ROS 节点名，避免机器人连接状态误报。
- 云端状态未知或不可用时仍可切回手动上传；开启自动模式及新增上传仍要求云端可达。

## 首次使用

先看 [记录器使用手册](docs/user-manual.zh-CN.md)（[English](docs/user-manual.md)），按正常流程操作；遇到异常再看排查部分：

1. 将已配置的树莓派、路由器 LAN 口及机器人连接到同一交换机。
2. 启动机器人的正常 ROS 发布器，安装器会自动识别 Humble/Jazzy 和初始域，不加载工作空间。
3. 运行一次安装命令：下载预编译桥，自动选择 ROS 环境，启用开机服务并集中检查连接。
4. 从 **Robot Recorder** 应用入口或浏览器打开配套树莓派的保留有线地址 `http://192.168.1.182:8080`，选择话题并录制；结束后查看、下载或删除。

树莓派由维护者预先配置。机器人需已有 ROS 2 Humble 或 Jazzy。桥包从树莓派获取，缺少的 ROS 依赖需要互联网。用户无需克隆仓库或手动构建；日常本地录制不依赖互联网。

## 日常使用

给套装和机器人通电，启动机器人的发布器，然后在能够通过以太网或 Wi-Fi 访问 Pi 的浏览器打开 **http://192.168.1.182:8080**。也可通过 NoMachine 进入机器人桌面，使用机器人上的浏览器。机器人桥自动启动，树莓派晚些可用时也会重新连接，无需保留桥终端。仅打开网页的电脑不需要安装 ROS 或 Zenoh。

下载文件保存在运行浏览器的电脑上：通过 NoMachine 使用机器人浏览器时，文件保存在机器人上。希望在自己的设备上预览或下载时，可直接由 Pi 上传云端，再用自己设备的浏览器打开云端网页。

确认 **Robot ROS domain** 与发布器一致，再选择话题录制；空闲时可改域并保存。树莓派接收域固定为 1。停止后等待收尾，再查看结果。套装地址改变或机器人保留其他网段的固定以太网地址时，按手册排查；本地名称地址仅作为可选快捷方式。

## 云端访问（可选）

云端网页：**https://154.8.234.96**。树莓派直接上传完成后，可在任何能上网的电脑登录、预览和下载云端副本。单话题和同步视图均支持拖动完整录制时间轴。Fast/HD 是抽样预览，原始下载不变。管理员可将云端录制移入回收站、恢复或永久删除；自动删除保持关闭。本地录制可独立使用。

请向项目维护者申请个人账号，登录资料私下提供。操作方法见[云端网页说明](docs/user-manual.zh-CN.md#云端网页)（[English](docs/user-manual.md#cloud-website)）。

## 可选增强：LoRa 远程控制

需要远距离操作时，使用配套 USB LoRa 电台及操作笔记本，按 [LoRa 说明](docs/lora-remote.zh-CN.md)（[English](docs/lora-remote.md)）安装。它提供话题选择、开始/停止、状态和简要录制管理；传感器数据仍走机器人到树莓派的以太网/Zenoh。

LoRa 控制端可离线安装，使用时无需树莓派 IP 或现场网络。GitHub 下载需互联网，首次配对口令由维护者私下提供。安装后从 **Robot Recorder LoRa** 应用入口启动后台控制端，无需保留终端；再次打开会复用已有实例。默认收到状态回复后等待一秒再请求；LoRa 页面不下载 bag。

## 仓库内容

[Pi v0.15.1 发布](https://github.com/FCosx/robot-recorder/releases/tag/v0.15.1)包含匹配的 LoRa 安装器、已校验的 v2 ARM64/x86_64 桥包、manifest 和校验和。编译后的 **Pi ARM64** 录制器仅用于已准备好的 Ubuntu 24.04/Jazzy 记录器维护更新，见[可执行文件说明](docs/recorder-executable.zh-CN.md)，不能直接完成空白 Pi 的部署；普通用户无需编译。

公开内容包括手册、机器人桥安装工具、LoRa 源码和加密配对授权。不公开录制/云端后端源码、登录凭据、明文配对、数据库、原始录制及私有构建归档。支持标准 ROS 消息类型，自定义类型暂不在支持范围。

机器人桥同时启动轻量带宽助手。刷新任一 UI 会在机器人端短暂采样；开始录制前必须关闭临时订阅。旧机器人可在记录器空闲时重跑手册安装命令，更新助手和自动启动设置。

LoRa 安装包含 pySerial 3.5，许可见 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 验收与后续工作

见 [Pi 验收与待验证项目](docs/pi-validation.zh-CN.md)（[English](docs/pi-validation.md)）。Lenovo → Pi 已完成 110 MiB/s 三分钟、80 MiB/s 五分钟测试，独立测量窗无缺失；SSD/USB 检查通过，CPU 峰值分别为 68.3°C／67.75°C。这些结果仅代表已测配置，不是通用无丢失上限。小包云端停止／恢复／录制优先及真实 RGB／深度／点云录制也已通过；Humble／ARM64 现场安装、NoMachine／Wi-Fi 访问和远距离 LoRa 仍待验收。
